How grouping works

TF–IDF weights distinctive English words. Average-link clustering joins responses with similar vocabulary. The grouping control changes the minimum cosine similarity. Shared words can hide disagreement, and paraphrases can land apart. Read the source notes before drawing conclusions. Data stays in memory until you reload.
